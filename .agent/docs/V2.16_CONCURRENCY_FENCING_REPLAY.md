## Correctness invariants

### Durable jobs

Authority is the conjunction:

```text
job.status is active
lease_expires_at > database time
job_id matches
worker_instance_id matches
fence_token matches
```

A PID is diagnostic only. Recovery atomically changes the worker instance and
increments the token. A stale worker cannot heartbeat, publish a result,
rollback a transaction or release a current lock. Infrastructure recovery does
not increment the logical `attempt_count`.

### Conditional rollback

Before restoring any file, rollback reads every current hash. A target is
eligible only when it still equals the changeset `new_hash`; a target already
at `base_hash` needs no action. Any other hash aborts restoration and records
`TENOR_CHANGESET_ROLLBACK_CONFLICT`. Evidence and newer bytes are preserved.

### Graphify causality

The workspace fingerprint algorithm is
`relative-path-size-content-sha256-v2`. Relative path, byte size and content
SHA-256 are causal; root binding remains a separate manifest field and `mtime`
is excluded. File identity is checked before and after bounded parallel
hashing. Publication revalidates the fingerprint and emits a monotone
`graph_epoch`.

At most one rebuild job is active. A pending rebuild has launch priority over
changesets, and the builder refuses every active changeset transaction.

### SCRIBE and tripwire

Canonical promotion serializes concurrent writers. File replacement,
deterministic `(entry_id, source_record_path, source_record_digest)` proof,
tripwire receipt and task-context flag commit together; failure restores the
previous file bytes. `summary` is mirrored into `l0_abstract`.

A tripwire exception for another active TENOR writer requires the exact current
hash, declared write intent, transaction, resource lock, live job lease,
worker instance and fence token. Missing SQL proof is surfaced and never
silently treated as authorization.
